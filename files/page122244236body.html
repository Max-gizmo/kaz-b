  • Права Администрации: Вправе в любой момент изменять, дорабатывать и обновлять Платформу без согласия Пользователя, а также устанавливать ограничения и проводить профилактические работы.
  • Запрещено: Размещать запрещенный Контент и совершать действия, нарушающие применимое законодательство.
  • Экспорт: Копирование программного кода Проекта разрешено только по согласованию с Администрацией.

2. Тарифы, Оплата и Возвраты

  • Возвраты: Денежные средства не подлежат возврату с момента активации Тарифа, поскольку право использования считается предоставленным. Возврат может быть осуществлен только по усмотрению Администрации.

  • Изменение Соглашения: Администрация вправе в одностороннем порядке изменять Соглашение, публикуя новую версию. Пользователь обязуется самостоятельно проверять изменения. Продолжение использования Платформы означает согласие с изменениями.
